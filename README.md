# One in a Cinnamillion

A three-prompt word game for the UBC MISA Cinnamon Bun Bake Sale (Tuesday, Nov 17, 10 AM to 4 PM, in front of Abdul Ladha, $3).
Rarer answers roll you deeper into the cinnamon bun; the last prompt always lands on the sale.

It is a single file: open `index.html`, or enable GitHub Pages (Settings, Pages, deploy from `main`, root) to get a public link.
Edit the prompts and answer lists in the `PROMPTS` array in the script.
