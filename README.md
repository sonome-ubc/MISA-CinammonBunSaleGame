# Sea Salt: a daily word dive

A five-prompt word game. Each answer lowers a bathysphere through the real ocean zones; the rarer the answer, the deeper it sinks.
Prompt 4 reveals the UBC MISA Cinnamon Bun Bake Sale (Tuesday, Nov 17, 10 AM to 4 PM, in front of Abdul Ladha, $3) as a surprise "one in a cinnamillion" answer.

It is a single file, `index.html`, served by GitHub Pages from `main`.
Edit the prompts and answer lists in the `PROMPTS` array in the script.
